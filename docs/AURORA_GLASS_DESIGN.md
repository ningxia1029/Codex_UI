# Aurora Glass Theme Studio

## 目标

Codex Aura 是频繁选择、预览和应用本地主题的桌面工具。v0.4 的界面方向为：

> 专业桌面工具 + 极光玻璃环境 + 克制的空间层级。

它不是营销页面，也不模仿游戏启动器。优先级依次是：看清当前主题、可靠地区分预览与应用、快速进入设置、必要时查看连接状态。

## 视觉结构

```text
极光壁纸环境层（暗化、缓存、静态渐变）
└── 半透明应用外壳
    ├── 主题库：选择与导入
    ├── 预览舞台：匿名 Codex 首页/任务页
    └── 主题检查器：主题信息、预览、设置、恢复
```

- 背景只提供氛围，正文始终落在深色玻璃层上；
- 通过透明度、亮度和阴影感区分背景、中景、前景，而非给所有区域加高对比边框；
- 一个选中主题只显示一个选中态，不重复套框；
- 运行日志默认收起，避免挤压主要工作区。

## 技术实现

当前实现保持 `PySide6 + QPainter + QPixmap`：

- `ThemeWorkspace` 绘制背景、暗化遮罩和两组静态极光径向渐变；
- `CodexPreviewCanvas` 使用匿名数据绘制模拟 Codex，不访问真实页面 DOM 或对话；
- `QPixmap` 在主题切换时加载一次，重绘时复用；
- 样式由 Qt Style Sheet 统一管理字体、圆角、间距、按钮和状态；
- 未引入 QML、Chromium 或实时模糊依赖，便携包结构保持不变。

## 性能边界

一张 2560×1440 的 RGBA 壁纸解码后约占 14 MiB。工作台仅缓存当前背景和预览所需的位图；不应同时保留大量原始 4K 图像。静态渐变的成本远低于在每次窗口缩放时运行 `QGraphicsBlurEffect` 或逐帧动画。

后续如果增加缩略图墙，应使用下采样缩略图和有限 LRU 缓存，而不是为每个主题长期保留全分辨率 `QPixmap`。

## 验收标准

1. 100%、125%、150%、200% Windows 缩放下无重叠、截断或白色空边；
2. 长主题名称可换行，主题列表和右侧检查器不横向溢出；
3. 壁纸切换后预览与背景一致，且不重复解码同一图片；
4. 预览、设置、恢复的语义可区分；
5. 视觉升级不改变 Codex 注入、连接或恢复行为；
6. 以真实 Windows 窗口检查字体和透明层；离屏测试只验证窗口能构造，不能替代原生视觉验收。
