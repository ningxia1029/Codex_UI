# Codex 主题工作台 MVP 规格

## 目标

为 Windows Codex Dream Skin 提供一个本地主题管理桌面应用。它让用户查看、预览、保存、切换并验证主题，但不修改 `WindowsApps`，也不绕过既有 PowerShell/Node 的安全检查与 CDP 注入逻辑。

## 已锁定的边界

- GUI：PySide6。
- 后端：随应用携带的 Codex Dream Skin PowerShell/Node 后端。
- 状态根目录：`%LOCALAPPDATA%\\CodexDreamSkin`，由后端统一管理。
- 主题格式：继续兼容既有 `theme.json` Schema v1。
- 预览：先在本地模拟 Codex 首页与任务页；应用到真实 Codex 必须由用户显式触发。

## MVP 用户旅程

1. 用户打开工作台，立即看到当前主题、运行状态和已保存主题。
2. 用户单击主题卡片，在不修改 Codex 的情况下查看首页/任务页模拟预览。
3. 用户点击“应用到 Codex”，后端切换主题并启动或重新应用皮肤。
4. 用户点击“验证当前皮肤”，工作台展示后端验证结论和日志。
5. 用户导入图片并应用，随后可将当前主题命名保存到主题库。

## 首个垂直切片

`读取主题库 → 本地预览 → 选择已保存主题 → 应用 → 刷新状态`

不在该切片内：在线主题市场、云同步、远程更新、复杂 CSS 编辑器、自动图片生成。

## 安全约束

- 所有主题文件读写均通过 PowerShell 后端。
- GUI 只解析后端返回的 JSON，不直接删除、覆盖或遍历主题根目录。
- 导入图片继续沿用既有尺寸、像素、大小和重解析点检查。
- 启动/恢复/验证复用既有互斥锁和 Store 包身份校验。
